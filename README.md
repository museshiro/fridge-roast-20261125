## The line

> My fridge spent 48 hours crafting one perfect ice sphere. I dropped it in tap water.

A dry-wit roast of a smart fridge's craft-ice maker: 48 hours of artisanal labor, wasted on tap water.

## How it works

`main.ts` writes the line to `/output/entry.txt`. Run it with Node 22:

```sh
node main.ts
```
